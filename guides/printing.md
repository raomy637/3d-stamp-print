# 切片与打印

## 底模（0.2 / 0.4 喷嘴）

| | 0.2 喷嘴（推荐） | 0.4 喷嘴（备选） |
|---|---|---|
| 层高 | 0.10 mm | 0.16 mm |
| 墙 | 4 | 4 |
| 填充 | 25% grid | 25% grid |
| 朝向 | 平板贴床、图案朝上 | 同左 |
| 支撑 | 不需要 | 不需要 |
| 顶面熨烫 | 仅顶面 | 仅顶面 |
| 前提 | 直接切 | 先加 `--min-stroke 0.9` |

追求最平印面可以用光面/玻璃板（纹理 PEI 会把纹路翻印到印面）；但要图案朝下时，浮雕窄缝必须靠桥接，宽缝容易塌。

## 边框

翼缘贴床、**刃口朝上**，0.4 喷嘴 0.16 层高、4 墙（1.2mm 墙正好 3 圈实心）、15% 填充、开 4mm brim。别开支撑；别用"仅外墙"模式——墙会变薄、切几次就崩口。

打完翻过来就是刃口朝下的切模，翼缘正好当手掌的按压台面。

## 手柄

底盘 φ14 贴床直立，不用支撑。6 联排只占 124×14mm，切片里把这一排复制成两三行就能凑满一盘；3 墙、15% 填充，实心也才 2.03cm³/个。

**层高按外观给，不按功能给**。手柄是天天上手摸的件，0.16 层高打出来一圈圈横纹很明显（实测：实体打印后确认横纹间距 = 层高）。这跟建模无关——手柄是 96 段旋转体，棱面误差 0.0027mm，比层高小 60 倍。

| | 0.4 喷嘴（省事） | 0.2 喷嘴（要手感） |
|---|---|---|
| 层高 | 0.12 | 0.08–0.10 |
| 外壁速度 | 35–45 mm/s | 30–40 mm/s |
| 外壁线宽 | 0.42 | 0.24 |
| 墙 / 填充 | 3 / 15% | 3 / 15% |
| 其它 | 开输入整形（振铃会把圆柱变出竖条）、Pressure Advance、风扇 100% | 同左；0.2 喷嘴整盘会慢一倍以上 |

别把 0.4 喷嘴降到 0.05 层高：挤出压力掉 22%，反而出现欠挤出条纹，实测 Ra 比 0.12 还高 18%。

最糙的位置是圆顶和收颈（两处斜面临近 45°）。FDM 45° 斜面粗糙度约是垂直面的 3 倍，这是几何决定的；用变层高（Orca/PrusaSlicer 的"自适应层高"）只在斜面掉到 0.08，比整件降层高省时间。

想再上一个档次：240 → 800 → 1200 目湿磨，25mm 的小件 30 秒，比降层高更快见效。

## 后处理

- 顶面熨烫后仍有层纹的：400 目砂纸轻轻过一遍图案面，别磨掉浮雕高度；
- 压粘土前在粘土上薄扑一层玉米淀粉/爽身粉，脱模干净；
- 边框刃口用几次后如果有粘土干结，温水泡软再刷，别用刀刮（0.4mm 刃口很容易崩）。
