# 切片与打印

## 底模（0.2 / 0.4 喷嘴）

| | 0.2 喷嘴（推荐） | 0.4 喷嘴（备选） |
|---|---|---|
| 层高 | 0.10 mm | 0.16 mm |
| 墙 | 8（第二道保险，见下） | 8（第二道保险，见下） |
| 墙生成器 | Arachne | Arachne |
| 填充 | **100%（底线）** | **100%（底线）** |
| 顶壳 / 底壳 | 6 / 4 | 6 / 4 |
| 朝向 | 平板贴床、图案朝上 | 同左 |
| 支撑 | 不需要 | 不需要 |
| 顶面熨烫 | **关**（见下） | **关** |
| 前提 | 直接切 | 先加 `--min-stroke 0.9` |

**底线是 100% 填充，第二道保险是 8 墙。** 凸起线条实测宽 1.27–2.98mm（见各单 `report.json` 的 `stroke_stats_mm`）。旧的 25% 稀疏填充就是蜂窝的直接原因：宽笔画中间只剩网格，顶面几层只是架在网格上的“屋顶”。100% 填充后笔画内部本来就是实心。再加 **8 墙**（0.4 喷嘴 0.42mm × 8 = 3.36mm ≥ 最大笔画 2.98mm）是为了让笔画内部连“可放填充的缝”都不存在——即使切片配置被改回 15–25%，也不会再出蜂窝；0.2 喷嘴线宽约 0.22mm，8 墙只覆盖 1.76mm，此时以 100% 填充为准（切片器允许更多墙时可取 `ceil(最大笔画 ÷ 线宽)`）。墙生成器用 **Arachne**：它按笔画宽度变线宽，窄笔画自动少几圈墙，不会变厚；Classic 会在中间留一条 gap-fill 细缝，又薄又容易断。顶壳至少 6（0.2mm 层高约 1.2mm 厚的实心顶）。

**图案件必须关顶面熨烫。** 熨烫是把喷嘴贴着顶面走一遍、靠挤出量把层纹压平，浮雕窄条（0.6–0.9mm）在那一刻会被压塌或削平；实物上的表现就是字母笔画断开、雪花细枝缺半截——模型本身是连续的。要平整印面用光面板 + 砂纸，不要靠熨烫。

想在窄线上看到“一圈一圈”的走线，把「顶部/底部表面图案」和「实心填充图案」选 **Concentric（同心）**。这只是切片路径样式，不改变模型；参考件那种细线整条由墙/同心线填满的观感，来源就是线宽足够窄 + 这种填充样式，而不是建模内部结构。

追求最平印面可以用光面/玻璃板（纹理 PEI 会把纹路翻印到印面）；但要图案朝下时，浮雕窄缝必须靠桥接，宽缝容易塌。

## 边框

翼缘贴床、**刃口朝上**，0.4 喷嘴 0.16 层高、4 墙（1.0mm 单壁正好 3 圈实心墙）、15% 填充、开 4mm brim。别开支撑；别用"仅外墙"模式——墙会变薄、切几次就崩口。

打完翻过来就是刃口朝下的切模，翼缘正好当手掌的按压台面。

## 合盘

`plate.stl` 把底模**套进边框内腔**、底面同贴床，两件仍是独立件，朝向不同：底模图案朝上，边框刃口朝上。底模比内腔单边小 `--cutter-clearance`（默认 0.8mm），这个缝就是为套着打留的。导入后保持同心位置，不要拖成左右分开，也不要把两个壳体合并成一个实体。底模四周的 0.8mm 缝放不下 brim，只给边框外圈加 brim 即可。合盘外框即边框外形（4 英寸约 112mm），不会超 P1S 热床。

## 手柄

底盘 φ15 贴床直立，不用支撑。6 联排只占 130×15mm，切片里把这排复制成两三行就能凑满一盘；3 墙、15% 填充，实心也才 2.05cm³/个。

**层高按外观给，不按功能给**。手柄是天天上手摸的件，0.16 层高打出来一圈圈横纹很明显（实测：实体打印后确认横纹间距 = 层高）。这跟建模无关——手柄是 96 段旋转体，棱面误差 0.0027mm，比层高小 60 倍。

| | 0.4 喷嘴（省事） | 0.2 喷嘴（要手感） |
|---|---|---|
| 层高 | 0.12 | 0.08–0.10 |
| 外壁速度 | 35–45 mm/s | 30–40 mm/s |
| 外壁线宽 | 0.42 | 0.24 |
| 墙 / 填充 | 3 / 15% | 3 / 15% |
| 其它 | 开输入整形（振铃会把圆柱变出竖条）、Pressure Advance、风扇 100% | 同左；0.2 喷嘴整盘会慢一倍以上 |

别把 0.4 喷嘴降到 0.05 层高：挤出压力掉 22%，反而出现欠挤出条纹，实测 Ra 比 0.12 还高 18%。

最糙的位置是圆顶和收颈（两处斜面临近 45°）。FDM 45° 斜面粗糙度约是垂直面的 3 倍，这是几何决定的；用变层高（Orca/PrusaSlicer 的"自适应层高"）只在斜面掉到 0.08，比整件降层高省时间。

想再上一个档次：240 → 800 → 1200 目湿磨，25mm 的小件 30 秒，比降层高更快见效。

## 后处理

- 图案面别熨烫（会把窄浮雕熨塌，见上文）；层纹明显的用 400 目砂纸轻轻过一遍图案面，别磨掉浮雕高度；
- 压粘土前在粘土上薄扑一层玉米淀粉/爽身粉，脱模干净；
- 边框刃口用几次后如果有粘土干结，温水泡软再刷，别用刀刮（1.0mm 单壁刃口磨圆了就切不利，得整件重打）。
