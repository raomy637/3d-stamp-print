# 三件套：边框 / 底模 / 手柄

## 为什么必须拆开

粘土饼干模具在真实使用里是三件东西，各自的寿命完全不同：

| 件 | 作用 | 换图案时 |
|---|---|---|
| **边框（切模）** | 只有一圈墙 + 刃口，切出粘土外形 | 外形变才换；同尺寸同轮廓可复用 |
| **底模（印章）** | 一整块板 + 凸起的图案，压在切好的粘土块上 | 必须重做 |
| **手柄** | 粘在底模背面，握着往下按 | 永远不用重做，一次打一批 |

以前把边框做在底模上（`--rim-w` 那种"外沿凸起一道"）是错的：那道凸起跟着底模走，等于每做一张图都要重新打一圈墙，而且墙和底板连在一起，刃口没法做薄、脱模也难。分体之后边框就是标准的"曲奇切模"，底模就是一块扁平的凸版。

## 尺寸链（谁比谁大多少）

```
--size 85          = 边框内腔（= 切出来的粘土外形）
底模外形 83.4      = size - 2 * cutter_clearance(0.8)   ← 单边 0.8 环隙
边框外形 95.0      = size + 2 * (wall 1.0 + flange 4.0)
边框高   15        = 1.6→12.0 主体 + 12.0→15.0 刃口段（两段同厚 = 单壁）
```

底模外形的算法：**先定内腔（= 剪影外扩 margin），底模由内腔再向内缩 clearance**。旧做法是"剪影外扩两次"各自求底模和内腔，两次独立外扩会在线宽窄于外扩量的 V 尖处跨接闭合，底模却保留 V 尖，于是窄缝处环隙从 0.8mm 跳到 3.5mm —— 这就是"外轮廓和底模对不上"的根因（2026-11-25 用 angel_dog 定量确认并修掉，改后全边界 100% 命中 0.80mm）。

环隙的作用：底模要能顺畅滑进边框内腔、又不晃。MakerWorld 的 Cookie Ejector 生成器把 0.4mm 当标准值[MakerWorld: Parametric Cookie Ejector Generator](https://makerworld.com/en/models/2678733-parametric-cookie-ejector-generator)，但那是光固化/机加工语境。FDM 实测（0.2 喷嘴、4 墙）0.4mm 设计值打完只剩 **0.28mm 净间隙**，直接卡死；**定稿 0.8mm**，实测净间隙 0.72–0.90mm，能松配。

## 边框的四个参数与出处

| 参数 | 取的值 | 依据 |
|---|---|---|
| `--cutter-height` | 15 | 定稿切割高度 1.5cm（用户口径）；主流区间 12–15mm。[MakerWorld: Cookie Cutter and Stamp Generator 2.0.1](https://makerworld.com/en/models/2466419-cookie-cutter-and-stamp-generator-2-0-1) |
| `--cutter-wall` | 1.0 | 单壁定稿：0.8–1.2 是干净切口的区间，取 1.0 与刃口同厚，整圈一个厚度好打印也更抗压 |
| `--cutter-edge` | 1.0 | 定稿不再做 0.4 薄刃（薄刃一碰就崩、且外侧两种厚度手感不一致）；要薄刃仍可显式传 0.4 找回旧版 |
| `--cutter-flange-w/t` | 4.0 / 1.6 | 底部翼缘（brim）：扩大贴床面积防翘边，翻过来还是手掌的按压台面。[MakerWorld: Ultimate Cookie Cutter](https://makerworld.com/en/models/2249022-ultimate-cookie-cutter-over-35-shapes-any-size) |

刃口段 3mm：外表面一次性收薄到 `--cutter-edge` 后垂直到底（`vertical`）；当它与 `--cutter-wall` 同值时外壁全程一条直线。**内腔全程不缩**，所以切出来的尺寸恒等于 `--size`。

## 打印朝向（三件各不相同）

| 件 | 朝向 | 支撑 | 原因 |
|---|---|---|---|
| 底模 | 图案朝上，平板贴床 | 无 | 图案朝下会被纹理 PEI 翻印，且浮雕窄缝需要桥接 |
| 边框 | **翼缘贴床、刃口朝上** | 无 | 刃口朝下会悬空 12mm；打完翻过来用，翼缘正好当握边 |
| 手柄 | 底盘贴床、直立 | 无 | 底盘 φ15 落地稳，25mm 高不到倒 |

边框记得开 **brim（3–5mm）**：翼缘虽然已经加宽了贴床面积，但 1.0mm 单壁的大周长件在 P1S 上仍可能局部起翘。

## 装配流程

1. 边框扣在粘土上压到底 → 得到一块外形精确的粘土；
2. 底模图案朝下，滑进边框内腔（0.8mm 环隙），手掌压手柄，图案压入粘土 2.5mm（边框高 15 托住底模，不会压穿）；
3. 一起拿起边框+底模，粘土留在桌上，脱模。

手柄粘在底模背面中心：酒精擦净 → 502 涂一圈 → 压 30 秒。做批量时可先把手柄粘好，模具就成了"一把握"。
