# 设计口径（2026-11-25 定稿四条，2026-11-27 增补线宽条）

起因：`angel_dog_100`（10cm 高天使狗线稿，`angel_dog_detail_v4.svg`）一单里连撞四个问题——镜像到底要不要、两腿之间的缝要不要填、图纸上的圆环怎么处理、边框外侧两种厚度要不要统一。逐条定量查清后固化成下面的口径，`src/stamp_pipeline.py` 已按此实现，`SKILL.md` 只留一行摘要，细节在这里。

## 1. 镜像：按「怎么压」分，不按「有没有文字」分

镜像发生在**把模具翻过来压**这一步，不是发生在「有没有文字」上。橡皮章/木版画都是同一个道理：版面上的画面，印出来必是左右相反的。

| 图型 | 结构 | 做法 | 用户拿 STL 跟原图比 |
|---|---|---|---|
| 带文案（饼干模具那种字） | 带手柄翻压 | **强制镜像**，不加 `--no-mirror` | 看到反了属正常，要解释一句 |
| 纯图案但有朝向（动物、人物、箭头、logo） | 带手柄翻压 | 镜像（默认） | 同上 |
| 纯图案但有朝向 | 平放正压（无手柄，手拿模具直接按） | `--no-mirror` | STL 与图同向 |
| 上下左右都对称（花、星、同心圆） | 任意 | 无所谓，默认镜像 | 看不出差别 |

判断只看一件事：**成品是「翻过来压」出来的，还是「正面直接按」出来的**。所以用户说「纯动物不要镜像」时，先把它翻译成「你要成品朝这个方向」还是「你要 STL 跟原图同向」，再决定 `--no-mirror`；不能把「纯动物」直接当 `--no-mirror` 的判据。

最快的判据是用户的实物照片：照片里成品朝左，那模具就该朝右。本单用户发来的红色打印件与镜像版 STL 同向，因此 `mirrored: true` 保留，只在汇报里留一句「若你要成品朝照片方向，一句话切 `--no-mirror`」。

## 2. 窄缝要做实心（`--close-gap`）

两腿之间、V 尖、两笔画之间的窄凹口，压泥时粘土会被挤进去，成品上多出一条本不存在的「筋」，脱模还容易撕边。这类窄缝要在几何上闭合：

```powershell
--close-gap 1.5    # 窄于 2×1.5=3mm 的凹口/窄缝填实
```

实现上分两步，缺一不可：

1. 形态学闭合 `cavity.buffer(1.5).buffer(-1.5)`，把缝口合上；
2. **把闭合出来的内腔全部填实**。只做第 1 步会在线宽大于 1.5 的湾里留下一个三角形内腔——等于在底模和边框内腔里凭空加一个洞，边框还会多长出一圈内刃。日志里的「窄缝闭合 1.5mm … 填掉 N 个内腔」就是这条。

阈值取 1.5 的依据：FDM 里窄于约 3mm 的凹口本来就压不进泥，留着只会挤出多余的泥；而宽度超过 3mm 的（例如尾巴卷成的真镂空）是设计的一部分，必须保留。angel_dog 本单：前腿内侧 V 缝 3.50mm、后腿与尾之间 2.94mm，闭合后两处都变平滑实心，尾部的卷曲镂空保留。

顺序很重要：`--close-gap` 在 `--hole` 之前做，否则通孔会被闭合吃掉。

### 2b. 「轮廓闭合 + 中间还要洞」不能用闭合，要走 `--void-mask` + 双刃

实心和镂空是两件事，很容易被混成一句「这里要闭合」：

- **粘土要实心**（多余的缝、会挤出筋的地方）→ `--close-gap`（上一节）。
- **粘土要镂空，但整块模具的外轮廓必须闭合** → 不能靠封缝（封了就没洞了，还会在缝口长出一条薄弱凸筋，用户照片红框就是这个），必须：

1. `--void-mask` 单独给一张挖空区掩码（黑 = 挖掉，与 `--input` 同尺寸同原点）；
2. 边框在内腔 `difference(void)`，于是洞口自然长出**一圈内岛刃**——刃宽 = 壁厚（1.0），刃口必须**闭合**，否则切不干净；
3. 内岛刃和外壳不相连，用 `--island-bridge 3.0` 在顶上搭一条 3.0mm 宽的**顶桥**（z 只占顶部 2mm，翻过来压时碰不到泥），两刃一体、一次打完；
4. **底模跟不跟着开洞，是两个不同的成品**：`--void-base both` = 底模同位置也开洞，泥被刃圈切开后往下漏，粘土上是真镂空；`--void-base cutter` = 底模整片留料，泥没处可去、只能被压紧，粘土上留下一个**闭合的三角线**（洞不穿）。angel_dog 用户先后要过两种，最后按"三角形闭合"出了 `cutter` 版。

洞离外轮廓至少留 2.5mm 料（`VOID_LAND_MM`），否则薄壁会被压裂。angel_dog 本单：两腿之间最窄 3.5mm 的湾，内缩 2.5mm 后挖空区 5.0 × 9.0mm，顶桥落在 (-24.0,-46.4) → (-21.0,-38.6)。

## 3. 圆圈/圆环 → 环形沉台 + 打孔通孔（`--hole` + `--pocket`）

图纸上独立的圆圈（光环、挂环圈、耳环圈）不能当普通线条刻成凸线，也不能把圈内直接挖空。要的成品是「一圈立起来的环 + 中间透孔」，所以要在**底模顶面铣一圈环形沉台**——粘土压进去正好凸起一圈环：

```powershell
--hole 988,386,6.0                                    # COL,ROW,孔径mm —— COL/ROW 是位图像素（左上原点）
--pocket=-1.65,31.99,3.0,4.8,1.0                       # CX,CY,RIN,ROUT,DEPTH —— 模型 mm，负数要写 = 形式
```

三条口径：

1. **底模要沉台，不要凸环。** 凸模凸起 → 成品凹陷，做凸环只会压出一圈凹槽，方向是反的；底模铣沉台，成品才是凸起的环。
2. **RIN = 吸管外径 / 2，ROUT = RIN + 1.8，DEPTH 1.0。** 沉台侧壁留 0.15mm 近似拔模（下窄上宽），出模不撕边。
3. **孔径 = 吸管外径。** 圆心同时开 `--hole` 通孔，φ6.0（吸管实测外径），压完泥正对这个孔，吸管一戳就穿。图纸上的小圆只作定位参考，孔径按吸管走。

angel_dog 本单：光环圆心 (620,269) px → 模型 (-1.65, 31.99)，沉台 内 r3.0 / 外 r4.8 / 深 1.0，配 φ6.0 通孔；预览与 3D 查看器里都能看到「槽 + 孔」，`preview.png` 的俯视图会画成浅灰环带 + 中央黑洞。

坑：沉台外沿（r4.8）别贴到外框环带（外框内沿 = 剪影外扩 margin 后的那圈）；贴了会被 `frame-mode silhouette` 当成外框整条删掉，而且不报错。

坑二：**图纸上原来那圈光环线必须抹掉**。它一般落在沉台外沿外 0.5–1mm（angel_dog 实测 r≈120px = 5.5mm），留着就是"圆圈外侧又出现一个圆环"。抹的时候只动**细节组**里的那一圈（`det & ~annulus(105–140px)`），千万别动外轮廓环带：环带被切一段就破环，`find_frame` 的填充比从 12 掉到 1.3，底面会退化成圆/方包络（症状：日志"未识别到外框"、`内腔 100.0x100.0`、底模变成圆盘）。

## 4. 边框只有一种厚度（单壁）


旧版是「1.2 主体 + 0.4 垂直薄刃」，外侧看是两种厚度，用户口径统一成**一种**：

```powershell
--cutter-wall 1.0 --cutter-edge 1.0     # 已是默认值
```

`build_cutter` 里主体段与刃口段取同一个 offset，外壁从翼缘一路直上到底，没有台阶。代价：刃口变厚（1.0 而不是 0.4），切口比刀口略钝，但抗压、不崩边、打印只要 3 圈实心墙。翼缘 4 × 1.6 保留（贴床防翘 + 翻过来当握边）。

想找回旧薄刃：显式 `--cutter-edge 0.4`，汇报时要说明「切口更利但容易崩口」。

## 5. 线宽与源稿：粗线靠切片、细线靠源稿（2026-11-27 增补）

蜂窝与"竞品直线观感"的根因都在**源稿线宽**，不在建模算法：竞品参考件实测 0.3–1.4mm ≈ 2 条挤出线，Arachne 沿笔画 2 条变宽墙即填实；我们存量件 1.3–3.0mm，墙盖不住才露填充。两条路线：

| 路线 | 源稿 | 切片 | 观感 |
|---|---|---|---|
| SVG 矢量收缩（首选） | `src/tools/svg_shrink.py`：描边式改 stroke-width、填充式距离变换腐蚀；外框 `--frame-mm 1.5` 单独加粗 | 默认 2–3 墙 + Arachne | 几何零漂移，顺笔画直线走线 |
| 位图代码归一 | `src/tools/monoline_normalize.py`，目标线宽受源稿最密间距限制 | 默认 2–3 墙 + Arachne | 同上，位图下限 0.6mm 级 |
| 粗线存量 | 不动 | 100% 填充 + 8 墙（0.4）+ Arachne + 顶壳 6 | 实心斜纹，无蜂窝 |

四条硬要求：

1. **禁止 `--stroke-cap` 上量产**（∩原区域留粗块、线宽不均匀，测试 RED）；**禁止生图模型重新创作订单图案**（构图/字形漂移）。收细只做「改线宽、不动几何」：SVG 改 stroke-width 或距离变换腐蚀；位图走骨架→剪毛刺→定半径重建，不做交集；验收测试 `tests/test_monoline_normalize.py`。
2. **目标线宽受源稿最密特征间距限制**：相邻平行笔画间距 < 目标线宽即并块。santa 位图实测上限 ≈0.6mm；SVG 无此限（矢量可任意细）。0.6mm 在竞品 0.3–1.4mm 区间内，0.4 喷嘴 1–2 条变宽墙填实。
3. **外框单闭合环、与图案分离、环自身面积 ≥2% 图幅**（`find_frame` 噪声门槛）。外框只取剪影不成浮雕线，可单独加粗（≈2–2.5% 图幅）；不满足 ⇒ `frame.reason=no_frame` ⇒ 退化圆底，属事故。花瓣/异形同此。
4. **AI 稿 prep**（仅备选重画路线）：多余内环按「填充比 >3 且 span 0.5–0.88」删除；只涂白删除区、保留灰度（纯 0/255 图 Otsu 阈值 = 0）。

核验落点与实测见 skill `references/monoline-source.md`；预览缺部件时以 STL 剖切为准（双环源稿触发预览渲染 bug）。

## 附：为什么「外轮廓和底模对不上」

根因不是模型错位，是**尺寸链条并行算了两次外扩**：

```
旧：base = 剪影.buffer(+1.2)      cutter腔 = 剪影.buffer(+2.0)
新：cavity = 剪影.buffer(+margin)  base = cavity.buffer(-0.8)   ← 内腔定基准，底模向内缩
```

两次独立外扩，在窄于外扩量的 V 尖处会各自「跨接」把尖角抹圆，而底模仍然保留 V 尖；于是底模到内壁的距离在绝大多数边界是 0.8mm，到了 V 尖处一下跳到 3.5mm——看上去就是「轮廓和底模对不上」。

angel_dog 修复前后（`check_v2.py`，排除孔口后统计）：

| 指标 | 旧（两次外扩） | 新（内腔定基准） |
|---|---|---|
| 最小 / p05 / 中位 | 0.80 / 0.80 / 0.80 mm | 0.80 / 0.80 / 0.80 mm |
| p95 / 最大 | 1.29 / **3.50 mm** | 0.80 / **0.80 mm** |
| 命中 0.80 的比例 | 91.6% | 100% |

另外 `place()` 原来对每个几何按自身 bbox 各自居中，多件之间会有亚毫米级隐藏错位；现在统一用参考轮廓的 bbox 求一个 `off`，`place()` 与打孔点 `place_pt()` 共用。
